Drop portable third-party tools in this folder (e.g. portable malware scanners,
disk utilities, file-recovery tools). Anything here is:

  - copied onto the USB drive with the toolkit, and
  - baked into the bootable WinPE image, available offline at X:\RescueToolkit\Extras

Use the "Extras" button in the toolkit to browse this folder.
Only include tools that run standalone without installation (no MSI/setup.exe
installers — WinPE cannot install software, only run portable executables).
